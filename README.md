# Kan Widget

داشبورد دسکتاپ برای Windows 10/11 با ظاهر تیره/روشن، پایش سیستم، میانبر برنامه‌ها، یادداشت، چک‌لیست و مدیریت سرورهای پروکسی.

## امکانات نسخه اولیه

- نمایش ساعت و تاریخ، مصرف CPU و RAM، فضای دیسک، سرعت دانلود/آپلود و زمان روشن‌بودن سیستم
- نمایش نام GPU در صورت نصب بودن ابزار `nvidia-smi`
- افزودن و اجرای برنامه‌ها و پوشه‌های دلخواه
- یادداشت سریع و چک‌لیست قابل ذخیره
- تم تاریک و روشن و حالت همیشه روی پنجره‌ها
- افزودن لینک تکی یا واردکردن Subscription و به‌روزرسانی فهرست سرورها
- انتخاب سرور و اتصال/قطع اتصال با هسته رسمی sing-box
- بازیابی تنظیمات پراکسی ویندوز هنگام قطع اتصال یا خروج از برنامه

### پروتکل‌های پشتیبانی‌شده در این نسخه

`VLESS`، `VMess`، `Trojan` و `Shadowsocks` با لینک‌های URI. اشتراک‌های YAML کلش، فایل JSON خام Xray، Hysteria2، TUIC و WireGuard هنوز در parser این نسخه پیاده‌سازی نشده‌اند.

> توجه: حالت اتصال فعلی از Windows System Proxy استفاده می‌کند؛ این تونل کامل TUN نیست. مرورگرها و برنامه‌هایی که پراکسی ویندوز را رعایت می‌کنند از اتصال استفاده می‌کنند، اما بعضی بازی‌ها یا برنامه‌ها ممکن است از آن عبور نکنند. برای TUN سراسری باید قابلیت جداگانه اضافه شود.

## اجرای مستقیم از سورس

1. Python 3.11 یا 3.12 را روی ویندوز نصب کن.
2. مخزن را دریافت کن.
3. روی `run_windows.bat` دوبار کلیک کن.

یا در ترمینال:

```powershell
py -3 -m pip install -r requirements.txt
py -3 kan_widget.py
```

## تست خودکار پروژه

با هر push به شاخه `main`، GitHub Actions تست‌های parser و راه‌اندازی اولیه رابط ویندوز را اجرا می‌کند. پیش از انتشار هم همین تست‌ها در Workflow ساخت ویندوز تکرار می‌شوند.

## ساخت فایل اجرایی ویندوز

فایل `build_windows.bat` را اجرا کن. خروجی در مسیر `dist\KanWidget\KanWidget.exe` قرار می‌گیرد.

## نصب با یک دستور PowerShell

بعد از انتشار اولین نسخه ویندوز در GitHub Releases، PowerShell را باز کن و این دستور را اجرا کن:

```powershell
irm https://raw.githubusercontent.com/kiankan/Kan-Widget/main/install.ps1 | iex
```

این دستور آخرین Release را دریافت می‌کند، فایل نصب را با SHA256 بررسی می‌کند، برنامه را در پوشه کاربر نصب می‌کند، میانبر دسکتاپ و Start Menu می‌سازد و برنامه را اجرا می‌کند. دسترسی Administrator لازم نیست.

برای انتشار اولین نسخه، در GitHub به **Actions → Build Windows app → Run workflow** برو و تگ `v0.1.1` را منتشر کن. بعد از پایان موفق Workflow، دستور بالا قابل استفاده خواهد بود.

## هسته VPN

در اولین اتصال، برنامه نسخه پایدار sing-box را از مخزن رسمی GitHub دریافت می‌کند و در پوشه زیر نگه می‌دارد:

`%APPDATA%\KanWidget\engine`

برای استفاده از این بخش، دسترسی به GitHub در اولین اجرا لازم است. هسته و فایل تنظیمات اتصال به‌صورت محلی ذخیره می‌شوند.

## داده‌ها و حریم خصوصی

تنظیمات، برنامه‌های انتخابی، یادداشت‌ها، فهرست سرورها و آدرس اشتراک روی همان کامپیوتر در مسیر `%APPDATA%\KanWidget` ذخیره می‌شوند. آدرس اشتراک ممکن است حاوی اطلاعات دسترسی باشد؛ آن را در اختیار دیگران قرار نده.

## محدودیت نسخه اولیه

این پروژه یک نسخه اولیه قابل توسعه است. پیش از استفاده دائمی، اتصال هر پروتکل را با سرور واقعی خودت آزمایش کن. فرمت‌های مختلف اشتراک ممکن است به پارسر اختصاصی نیاز داشته باشند.
